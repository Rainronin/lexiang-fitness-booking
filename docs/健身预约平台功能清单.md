# 乐享健身预约平台 · 功能清单

> 日期：2026-08-08（初版）；2026-08-29（UI 验收后同步）
> 配套文档：《健身预约平台项目计划.md》（架构 / 数据模型 / 业务规则 / API 清单）
> 用途：开发时对照勾选（[ ] → [x]），确保两个端每个功能点都落地；M4 验收时逐项核对
> 约定：所有列表页支持分页；删除类操作需二次确认；表单校验必填项齐全；加载中/空数据/错误均有状态提示

## 一、项目一 · 乐享健身预约管理平台（admin-web）

### 1. 登录与权限
- [x] 登录页：账号 + 密码表单，错误提示（账号或密码错误）；注：后台账号无停用状态（admin 表无 status 字段），「账号已停用」为会员端提示
- [x] 登录成功：token + 用户信息存 localStorage（Pinia + 持久化），跳转工作台
- [x] 路由守卫：无 token 访问受限页 → 跳登录；登录后访问登录页 → 跳工作台
- [x] 角色权限：员工隐藏【营收统计】【预约规则】菜单；直接输入 URL 访问被守卫拦截（403 页）
- [x] 侧边菜单按角色动态渲染（管理员 7 项 / 员工 5 项，排班设置从教练管理进入不占菜单项）
- [x] 侧边菜单折叠后仍为每个图标提供可读名称，支持键盘与读屏识别
- [x] 401 统一处理：token 失效自动跳登录并清除本地登录态
- [x] 退出登录：清除 token，跳登录页

### 2. 工作台看板（管理员/员工可见）
- [x] KPI 卡片 4 张：今日预约数、今日课程数、今日上座率、本月营收
- [x] 近 7 日预约趋势折线图（ECharts）
- [x] 热门课程 TOP5 柱状图（ECharts）
- [x] 本月每日营收折线/柱状图（ECharts）
- [x] 图表无数据时显示空态提示

### 3. 会员管理
- [x] 会员列表：分页表格（手机号/昵称/性别/状态/注册时间）
- [x] 搜索筛选：手机号或昵称关键字、状态（正常/停用）
- [x] 新增会员：弹窗表单（手机号唯一性校验、昵称、性别）
- [x] 编辑会员：同表单回填
- [x] 状态切换：启用/停用（停用二次确认，提示"停用后不可预约"）
- [x] 停用会员预约列表操作仍可查看

### 4. 课程管理
- 分类管理
  - [x] 分类列表（名称/排序/状态）
  - [x] 新增/编辑分类（弹窗）
  - [x] 删除分类（分类下有课程时禁止并提示）
- 课程管理
  - [x] 课程列表：分页表格（封面缩略图/名称/分类/价格/时长/状态）
  - [x] 搜索筛选：分类、关键字、状态（上架/下架）
  - [x] 新增/编辑课程：表单（名称、分类下拉、封面图上传、价格、时长、简介）
  - [x] 图片上传：JPG / PNG / WebP，最大 2MB；前端预检并显示上传状态，完成后预览回显（支持移除）
  - [x] 上架/下架切换
  - [x] 删除课程（有排班时禁止并提示）

### 5. 教练管理
- [x] 教练列表：分页表格（头像/姓名/头衔/简介/状态）
- [x] 新增/编辑教练：表单（姓名、头像上传、头衔、简介）
- [x] 删除教练（有排班时禁止并提示）
- [x] 排班设置（进入教练排班页）：
  - [x] 周视图：7 列（周一~周日）× 6 时段格子的排班表
  - [x] 点击空格新增排班：选择课程 + 容量（默认值）
  - [x] 已有排班显示课程名 + 容量，可修改容量 / 删除
  - [x] 冲突提示：同教练同时段已存在排班时禁止并提示
  - [x] 保存按钮提交整周排班（全量覆盖）
  - [x] 排班格子支持 Tab / Enter / Space；存在未保存修改时，离开路由或刷新页面会提示确认

### 6. 预约管理
- [x] 预约列表：分页表格（会员手机号/课程/教练/日期/时段/状态/提交时间）
- [x] 筛选：日期（单日选择）、课程下拉、状态（已确认/已取消/已完成）、会员关键字
- [x] 后台取消预约：仅 confirmed 可取消，二次确认，取消后名额释放
- [x] 状态展示：confirmed（已确认）/ cancelled（已取消）/ completed（已完成）

### 7. 预约规则（仅管理员）
- [x] 规则配置表单：提前预约天数（数字输入，1~30）、每会员每日预约上限（1~10）
- [x] 保存成功提示，刷新后生效

### 8. 营收统计（仅管理员）
- [x] 统计方式切换：按日 / 按月
- [x] 日期范围选择（默认近 30 天）
- [x] 营收折线图 + 汇总（总营收/订单数/客单价）
- [x] 课程热度排行表：课程名 + 预约次数 + 营收（降序）

## 二、项目二 · 乐享健身会员端（miniapp，uni-app）

### 1. 首页
- [x] 顶部搜索/分类 tab：全部 + 各课程分类，切换刷新列表
- [x] 课程卡片列表：封面、名称、价格、教练（若有）、时长
- [x] 热门推荐区：按预约热度取 TOP 3 课程卡片横滑
- [x] 下拉刷新、加载更多（分页）
- [x] 点击课程 → 课程详情页

### 2. 课程详情
- [x] 课程信息：封面大图、名称、价格、时长、简介
- [x] 教练介绍：头像、姓名、头衔（关联教练）
- [x] 可预约时段：未来 N 天（规则 advance_days）的排班列表，显示日期 + 时段 + 剩余名额（剩余=capacity-已约）
- [x] 名额为 0 的时段置灰不可选
- [x] 预约按钮：未登录 → 跳登录页；已登录 → 跳预约确认页（携带选中排班）
- [x] 已下架课程不可进入/提示
- [x] 详情页顶部返回导航固定在视口内，滚动后仍可操作

### 3. 预约确认
- [x] 展示课程信息摘要 + 已选日期/时段 + 价格
- [x] 确认提交 → 校验通过则成功（跳转"我的预约"或成功提示）
- [x] 拦截提示（后端校验失败时展示具体原因）：名额不足 / 同课重复预约 / 超出每日预约上限 / 超出可预约天数 / 账号已停用
- [x] 提交中 loading 防重复点击

### 4. 我的预约
- [x] Tab 切换：待上课（confirmed 且日期≥今天）/ 已完成（completed）/ 已取消（cancelled）
- [x] 预约卡片：课程名、日期、时段、教练、状态标签
- [x] 取消预约：confirmed 且距开课 > 2 小时可取消，二次确认；距开课 ≤ 2 小时按钮置灰并提示
- [x] 空状态提示

### 5. 我的
- [x] 未登录态：显示"点击登录"入口
- [x] 已登录态：头像/昵称/手机号展示
- [x] 签到：今日未签到显示签到按钮，点击成功弹提示（+1 天）；已签到显示"今日已签到"
- [x] 签到记录：近 30 天签到日期列表（或日历点阵）
- [x] 退出登录

### 6. 登录/注册
- [x] 手机号输入（11 位校验）+ 验证码输入（6 位）
- [x] 手机号/验证码使用文本值承载并唤起数字键盘，具备可读名称；校验失败时焦点回到对应字段
- [x] "获取验证码"按钮：点击后调用 send-code，提示"验证码已发送（模拟：123456）"，60 秒倒计时
- [x] 登录成功：token 持久化，返回来源页（或我的页）
- [x] 首次登录自动注册（手机号不存在时创建会员）

## 三、后端服务（server）

### 1. 基础设施
- [x] Express 应用：JSON 解析、全局 CORS、静态资源（uploads/）、错误处理中间件
- [x] better-sqlite3 连接（data.db），建表 + 种子数据一键初始化（npm run seed）
- [x] 统一响应格式 { code, data, message }
- [x] JWT 签发/校验中间件（区分 admin / member 角色）

### 2. 接口实现（按计划第 6 节 API 清单逐条实现）
- [x] auth：admin/login、member/send-code、member/login、me
- [x] members：列表（筛选+分页）、新增、编辑、状态
- [x] categories：增删改查（删除保护）
- [x] courses：增删改查（含 status 上下架、图片上传 multer）
- [x] coaches：增删改查（删除保护）+ 排班获取/保存（冲突校验、全量覆盖）
- [x] schedules：列表筛选
- [x] bookings：后台列表筛选、后台取消；会员端列表、提交（事务校验）、取消（2 小时规则）
- [x] rules：读取、更新（单行配置）
- [x] stats：dashboard（今日预约数/上座率/本月营收/7 日趋势/TOP5）、revenue（日/月聚合）、course-hot
- [x] signin：签到（同日幂等）、签到记录

### 3. 核心逻辑
- [x] 预约提交事务：BEGIN → 校验名额/冲突/规则/会员状态 → INSERT → COMMIT（防并发超卖）
- [x] 已完成状态判定：查询时 booking_date < 今天 && status=confirmed → 返回 completed
- [x] 名额计算：某 schedule 某日 confirmed 数（取消后自动释放）
- [x] 统计聚合：SQL GROUP BY 按日/月/课程聚合营收与预约数

## 四、通用交互与验收约定

- [x] 所有表单：必填校验、提交 loading、成功/失败 toast
- [x] 所有列表：分页、空数据占位、加载骨架或 loading
- [x] 时间展示统一 YYYY-MM-DD HH:mm；日期操作统一 YYYY-MM-DD
- [x] 后台表格操作列：编辑/删除（或状态切换）按钮，危险操作二次确认
- [x] 关键图标操作具备可访问名称，键盘焦点清晰，错误字段可直接定位
- [x] 代码注释：模块入口、复杂逻辑（事务/冲突校验/统计 SQL）处添加说明注释
