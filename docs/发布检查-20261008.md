## 项目现状

项目包含 Vue 3 管理后台、uni-app 会员端和 Express / SQLite 后端。当前实现包含课程与教练管理、每周排班、会员预约与取消、签到、角色权限、经营统计及原创演示图片；会员目标端为 H5 与微信小程序。

## 修正内容

- 后端 `package.json` 原先遗漏全部运行依赖，已按现有锁文件补齐，并同步锁文件项目名称。
- 会员端原锁定 Pinia 2.3.1，要求 Vue ≥ 3.5.11，与 uni-app 使用的 Vue 3.4.21 冲突，普通 `npm ci` 会报 `ERESOLVE`。现锁定兼容的 Pinia 2.2.2、Vue / `@vue/runtime-core` 3.4.21，以及符合 uni-app peer 要求的 `@dcloudio/types` 3.4.31；未通过强制忽略 peer 依赖绕过问题。
- 后端 `better-sqlite3` 13 自带各平台原生模块；默认安装会额外触发 node-gyp，本机缺少 Visual Studio C++ 工具链而失败。已验证 `npm ci --ignore-scripts` 可正常安装并加载包内 SQLite 模块，并将此命令写入 README。
- 根目录忽略规则覆盖环境文件、私钥格式、SQLite 数据及 WAL / SHM、上传目录、依赖、构建、微信本地配置和临时核验文件；`.env.example`、演示插画和 TabBar 图标保留。
- 新增完整 README 和会员端接口地址示例，项目计划与协作说明同步公开仓库定位，学习指南中的本机桌面路径改为通用示例路径。

## Git 发布方式

本地旧历史曾跟踪 SQLite WAL / SHM、临时截图和已移出的求职笔记；仅新增 `.gitignore` 无法让旧提交中的内容消失。

因此保留本地 `master` 历史，另以检查后的当前文件树创建无历史父提交的公开源码快照，在本地使用 `codex/github-public` 分支，推送为远程 `main`。仅推送该分支，不推送旧分支或标签。后续公开更新应继续基于该公开分支提交，避免将旧本地历史合并回公开分支。

后端冒烟仅在本次创建的隔离目录中初始化、写入和测试。测试服务已停止，隔离副本保留在被 Git 忽略的 `.verify/github-release-20261008/`，未随源码上传。原有数据库、上传图片、核验截图和 `miniapp/dist/build/mp-weixin` 运行产物继续保留。
