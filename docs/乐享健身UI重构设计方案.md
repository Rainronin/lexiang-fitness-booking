# 乐享健身 UI 重构设计方案

> 文档状态：设计方向已确认，双端实施与 UI 验收均已完成  
> 适用范围：admin-web 管理后台、miniapp 会员端  
> 设计主题：轻盈系统 × 训练节奏  
> 核心约束：保留 Element Plus、uni-app、接口和全部业务逻辑，仅重构视觉、组件状态、交互反馈与动效  
> 更新日期：2026-09-07（初版 2026-08-29；§6.3 含 2026-09-07 侧栏修复补充）

## 一、设计目标

本次重构不改变现有功能与数据流，目标是将当前可用但偏脚手架风格的界面，升级为具有苹果式清晰层级、细腻材质和丝滑反馈的健身预约产品。

重构后的体验应同时满足两个场景：

- 管理后台：信息密度高，但不拥挤；运营人员可以快速扫描数据、筛选记录并完成配置。
- 会员端：内容更有吸引力，预约路径更清楚，关键状态始终有即时、连续的反馈。

### 1.1 成功标准

- 两端使用同一套品牌色、语义色、圆角、间距和动效语言。
- Tab、导航栏、下拉框、按钮、输入框、表单校验、弹窗、表格、卡片和状态反馈全部具备完整状态。
- 核心操作有明确的按下、加载、成功、失败和禁用反馈。
- 页面切换、内容进入和状态变化保持连贯，不出现突兀闪烁或无意义动画。
- 后台在 1024px 及以上宽度可正常使用；会员端兼容 H5 和微信小程序安全区域。
- 不增加新的 UI 框架，不改变接口参数、权限、预约规则或状态流转。

### 1.2 非目标

- 不新增业务模块、接口、字段或数据统计口径。
- 不重写 ProTable、ProForm、Chart 的业务职责。
- 不为了视觉效果复制 Apple 的商标、图标、系统页面或 Fitness 圆环。
- 不在所有容器上使用毛玻璃，不使用持续运行的装饰动画。
- 不引入动画库；优先使用 CSS transition、animation 和 uni-app 原生能力。

## 二、现状审计

### 2.1 已有优势

- 功能链路完整，后台和会员端均已通过业务验收。
- admin-web 已封装 ProTable、ProForm、Chart，适合集中完成组件级升级。
- miniapp 页面数量可控，卡片、预约、登录和个人中心的结构清楚。
- 两端错误信息、加载状态和权限处理已有基础，不需要重新设计数据流。

### 2.2 当前主要问题

| 问题 | 当前表现 | 影响范围 |
|---|---|---|
| 缺少设计令牌 | 颜色、圆角、阴影分散在页面样式中 | 两端全部页面 |
| 模板感较强 | 后台以 Element Plus 默认蓝和深色侧栏为主，会员端为常见蓝白渐变 | 品牌辨识度 |
| 信息层级偏平 | 多数后台页面直接从搜索区或表格开始，缺少页面标题和任务说明 | 管理后台 |
| 组件状态不完整 | hover、pressed、focus、loading、invalid 的视觉语言不统一 | 表单和操作组件 |
| 动效缺乏体系 | 主要依赖组件默认动画，页面与状态切换缺少连续性 | 两端全部页面 |
| 材质使用单一 | 白色卡片与浅灰背景重复，缺少前后层次 | 两端全部页面 |
| 后台响应式不足 | 固定 220px 侧栏和固定栅格，窄屏容易拥挤 | admin-web |
| 会员端导航普通 | 原生蓝色导航栏、纯文字 TabBar、热门区使用 emoji | miniapp |
| 图片表现较弱 | 当前种子数据为纯渐变占位图，课程差异主要依靠文字 | 课程相关页面 |

### 2.3 样式集中位置

- admin-web/src/style.css：当前仅包含基础重置、页面卡片和搜索栏。
- admin-web/src/layout/MainLayout.vue：侧栏、顶栏和主内容布局。
- admin-web/src/components：表格、表单和图表的统一升级入口。
- miniapp/src/App.vue：会员端全局页面、卡片、价格和空状态样式。
- miniapp/src/uni.scss：仍以 uni-app 默认变量为主，可改为品牌设计令牌入口。
- miniapp/src/pages.json：导航栏和 TabBar 的全局样式入口。

## 三、设计概念：轻盈系统 × 训练节奏

苹果式体验的重点不是外观模仿，而是内容优先、层级清楚、状态连续、触控可信。健身主题则通过更有力量的数字、节奏化间距和一处明确的活力色表达。

### 3.1 视觉关键词

- 清晰：重要信息一眼可见，弱化不影响当前任务的内容。
- 轻盈：减少厚重边框，用留白、色差和柔和阴影建立层级。
- 精确：表格、金额、容量和日期使用稳定对齐。
- 活力：珊瑚橙只用于课程价格、运动提示和关键强调。
- 连续：组件状态之间平滑过渡，避免内容突然消失或跳位。

### 3.2 标志性元素：训练动态胶囊

“训练动态胶囊”是本次设计唯一重点强化的标志性元素。

会员端使用场景：

- 课程详情页展示所选日期、时段和剩余名额。
- 预约提交时从操作按钮平滑切换为加载状态。
- 预约成功后在同一位置切换为成功状态，再进入“我的预约”。
- 签到成功、取消预约等短时任务使用同一反馈语言。

后台使用场景：

- 排班页面显示未保存变更、保存中和已保存状态。
- 筛选生效时用紧凑状态胶囊显示当前条件数量。
- 长操作或重要保存使用页面内状态反馈，不只依赖右上角消息。

动态胶囊不替代按钮、Toast 或表单错误，只负责连接一个任务的连续状态。

## 四、设计令牌

设计令牌使用语义命名。admin-web 映射为 CSS 自定义属性和 Element Plus 主题变量；miniapp 映射为 SCSS 变量及全局类。

### 4.1 色彩系统

| 令牌 | 色值 | 用途 |
|---|---:|---|
| 品牌主色 | #007AFF | 主按钮、选中态、链接、键盘焦点 |
| 品牌深色 | #0056B3 | 主按钮按下态、强调文字 |
| 活力珊瑚 | #FF6B4A | 价格、健身活力点、重点数据 |
| 成功绿色 | #30B56A | 成功、正常、可预约 |
| 警告琥珀 | #F5A524 | 临界容量、待处理提醒 |
| 危险红色 | #E5484D | 删除、停用、校验失败 |
| 主文字 | #1D1D1F | 标题、正文、关键数据 |
| 次级文字 | #6E6E73 | 辅助信息、说明 |
| 弱化文字 | #98989D | 占位符、禁用提示 |
| 页面背景 | #F5F5F7 | 两端主背景 |
| 一级表面 | #FFFFFF | 卡片、表格、表单 |
| 二级表面 | #F0F1F3 | 控件背景、分组区域 |
| 分隔线 | rgba(60, 60, 67, 0.12) | 表格、列表和输入框边界 |
| 深色导航 | #17181A | 后台侧栏，仅用于结构导航 |

色彩规则：

- 主色负责“可以操作”，珊瑚色负责“值得关注”，两者不可同时抢占同一层级。
- 成功、警告、危险色只表达真实状态，不作为装饰色。
- 页面背景与卡片不依赖重阴影区分，优先使用色差和间距。
- 图表系列默认使用主色、珊瑚色、绿色、紫蓝色的固定顺序。

### 4.2 字体系统

字体栈：

- 中文正文：-apple-system、BlinkMacSystemFont、PingFang SC、Microsoft YaHei、sans-serif。
- 英文与数字：优先使用系统 SF 字体；无对应字体时自然回退。
- 表格数字、金额、日期和 KPI 开启 tabular-nums，保证数位对齐。

| 层级 | 后台建议 | 会员端建议 | 用途 |
|---|---:|---:|---|
| 展示数字 | 32px / 700 | 48rpx / 700 | KPI、价格、签到天数 |
| 页面标题 | 24px / 700 | 40rpx / 700 | 页面主标题 |
| 分区标题 | 17px / 600 | 32rpx / 600 | 卡片标题、模块标题 |
| 正文 | 14px / 400 | 28rpx / 400 | 默认内容 |
| 辅助文字 | 12px / 400 | 24rpx / 400 | 说明、时间、状态 |

### 4.3 间距系统

统一以 4 为基础单位：

- 4：图标和文字的紧凑间距。
- 8：同一控件内部间距。
- 12：紧凑组件间距。
- 16：标准组件间距。
- 24：卡片内边距和模块间距。
- 32：页面主要分区间距。
- 48：大区块或登录页留白。

禁止出现没有语义的零散间距值。现有 10、14、18、20 等值在重构时归并到最近的设计令牌。

### 4.4 圆角系统

| 圆角 | 用途 |
|---:|---|
| 8px | 小标签、表格内控件、提示条 |
| 12px | 输入框、按钮、下拉面板 |
| 16px | 普通卡片、弹窗、筛选区 |
| 20px | 移动端课程卡、登录卡 |
| 999px | 状态胶囊、分段控制器、头像 |

圆角使用连续递增关系。小控件不使用大圆角，避免所有元素都变成胶囊。

### 4.5 阴影与材质

| 层级 | 建议样式 | 用途 |
|---|---|---|
| 表面 0 | 无阴影 | 页面背景、表格主体 |
| 表面 1 | 0 1px 2px rgba(0,0,0,.04) | 普通卡片 |
| 表面 2 | 0 8px 24px rgba(0,0,0,.08) | 下拉框、Popover |
| 表面 3 | 0 20px 60px rgba(0,0,0,.14) | Dialog、重要浮层 |

毛玻璃材质仅用于：

- 后台顶栏。
- 会员端自定义导航和底部固定操作区。
- 动态胶囊与临时浮层。

在不支持 backdrop-filter 的环境中回退为 94% 不透明的实色背景。

### 4.6 图标

- 后台继续使用 @element-plus/icons-vue，不增加图标依赖。
- 图标统一使用 1.75px 至 2px 的视觉线宽。
- 不再使用 emoji 作为正式功能图标，例如首页“🔥”和后台“🏋️”。
- 小程序 TabBar 优先补充同风格本地图标；未制作图标前保留文字，不使用混杂风格素材。

## 五、动效系统

### 5.1 动效原则

- 动效解释变化，不装饰静止页面。
- 同一操作只安排一个主要动画。
- 元素退出比进入更快，避免操作拖沓。
- 列表刷新保持容器稳定，不让页面整体跳动。
- 所有持续时间较长的操作必须有明确 loading，不以无限呼吸动画代替进度反馈。

### 5.2 时长

| 类型 | 时长 | 场景 |
|---|---:|---|
| 即时反馈 | 80–120ms | 按下、hover、图标响应 |
| 控件切换 | 180–220ms | Tab、下拉框、校验状态 |
| 浮层进入 | 240–280ms | Dialog、Popover、Toast |
| 页面进入 | 320–360ms | 路由页面、详情页内容 |
| 成功反馈 | 480–600ms | 动态胶囊状态完成 |

### 5.3 缓动

- 标准进入：cubic-bezier(0.22, 1, 0.36, 1)。
- 标准退出：cubic-bezier(0.4, 0, 1, 1)。
- 弹簧感反馈：cubic-bezier(0.2, 0.9, 0.2, 1.15)，只用于小幅缩放和选中态。
- 不使用过度回弹，不让表格、表单或大面积容器弹跳。

### 5.4 动画模式

| 场景 | 动画 |
|---|---|
| 按钮按下 | 缩放至 0.98，阴影收紧 |
| Tab 切换 | 选中底板滑动，文字颜色交叉过渡 |
| 下拉框 | 轻微上移 6px + 淡入，关闭反向执行 |
| 表单错误 | 边框和说明淡入；不抖动整个表单 |
| 卡片进入 | 淡入 + 上移 8px，列表最多错开 30ms |
| Dialog | 遮罩淡入，面板缩放 0.98 至 1 |
| Toast | 顶部下移进入，内容变化保持同一容器 |
| 数字更新 | 仅 KPI 使用轻微淡出、上移和替换 |
| 加载完成 | 骨架与真实内容交叉淡化，不改变容器高度 |
| 预约成功 | 动态胶囊宽度收紧，加载环切换为勾选 |

### 5.5 性能与减少动态效果

- 高频动画只使用 transform 和 opacity。
- 避免对 width、height、top、left 进行连续动画；动态胶囊可使用离散状态切换配合 transform。
- 毛玻璃只出现在小面积固定层，不作用于长列表。
- 支持 prefers-reduced-motion；开启后取消位移、缩放和错峰，只保留 80ms 淡入淡出。
- 小程序端不使用大面积 filter、复杂粒子或 Canvas 装饰。

## 六、通用组件规范

### 6.1 按钮

按钮层级：

- 主按钮：每个视觉区域最多一个，品牌蓝填充。
- 次按钮：浅灰表面，深色文字。
- 幽灵按钮：透明背景，用于次级工具操作。
- 危险按钮：仅确认删除、停用和取消预约时使用红色。
- 链接按钮：仅用于表格行内低风险操作。

状态要求：

| 状态 | 表现 |
|---|---|
| 默认 | 清晰标签、稳定尺寸 |
| Hover | 背景轻微加深，阴影提升一级 |
| Pressed | 缩放 0.98，阴影收紧 |
| Focus | 2px 主色焦点环，与组件保持 2px 间距 |
| Loading | 文案保持或切换为明确动词，不改变按钮宽度 |
| Disabled | 降低对比度，取消阴影和动画 |

文案使用动作结果，例如“保存排班”“确认预约”“移除图片”，不使用含糊的“确定”作为所有场景的统一文案。

### 6.2 Tab 与分段控制器

- 页面一级 Tab 使用分段控制器式底板，适合课程管理/分类管理、按日/按月等少量选项。
- 内容型横向分类使用可滚动胶囊 Tab，选中项有实体底色。
- 预约状态 Tab 使用文字 + 滑动指示条，保持列表空间。
- 切换时保留容器高度，避免页面抖动。
- 键盘环境支持方向键切换，触控目标不小于 44px。

### 6.3 导航栏与侧栏

后台侧栏：

- 宽度保持 220px，增加 72px 折叠态作为窄屏方案。
- 深色导航只承担结构，不使用大面积渐变。
- 当前项使用浅色圆角底板高亮（曾设左侧短强调线，因视觉上被误读为文本光标，2026-09-07 移除）；菜单文本 `user-select: none`，抑制浏览器「使用文本光标浏览页面」（caret browsing）在菜单文字上显示闪烁光标（2026-09-07）。
- 品牌区使用简洁字标和抽象运动轨迹图形，替换 emoji。

后台顶栏：

- 使用半透明浅色表面和细分隔线。
- 左侧显示页面标题与必要面包屑，避免“首页 / 当前页”的重复信息。
- 右侧整合角色、用户名和退出菜单，减少多个分散控件。

会员端导航：

- 页面标题简短，内容页返回按钮保持原生认知。
- 滚动时导航从透明过渡到半透明实色。
- H5 和微信端使用平台允许的能力分别实现，视觉语义保持一致。

会员端 TabBar：

- 半透明浅色背景，顶部细分隔线。
- 选中项使用主色图标与文字，轻微上移 1px。
- 不做悬浮大胶囊，避免遮挡原生安全区域。

### 6.4 输入框、下拉框与日期组件

- 默认背景为二级表面，弱边框；聚焦时切换为白色表面和主色焦点环。
- 输入高度后台为 40px，会员端触控高度不小于 48px。
- 标签始终可见，不仅依赖 placeholder 表达字段含义。
- 下拉面板使用 12px 圆角、表面 2 阴影和 6px 进入位移。
- 选项 hover 与选中使用不同强度，已选项附带勾选图标。
- 日期范围组件在窄屏拆为上下布局，不压缩文字。
- 数字输入明确单位，单位不写进字段值。

### 6.5 表单校验

校验状态：

- 未填写：保持中性，不提前显示红色。
- 聚焦：显示主色焦点环。
- 校验失败：边框转危险色，字段下方显示具体修正方法。
- 校验成功：不在每个字段展示绿色勾，避免视觉噪声。
- 提交失败：滚动并聚焦第一个错误字段。
- 服务端错误：优先绑定到相关字段；无法定位时显示表单顶部错误摘要。

错误文案示例：

- “手机号格式不正确”改为“请输入 11 位手机号”。
- “参数不完整”在可定位场景改为“课程时段已失效，请重新选择”。
- “保存失败”保留后端具体原因，并提供重新尝试入口。

错误状态使用颜色、图标和文字三重表达，不能只依靠红色。

### 6.6 卡片

- 卡片由内容关系决定，不把每段内容都包进独立白框。
- 普通卡片使用 16px 至 20px 圆角和表面 1 阴影。
- 可点击卡片具有 hover、pressed 和键盘 focus 状态。
- 图片卡片优先保持统一比例，加载前使用相同比例骨架。
- KPI 卡片减少彩色方块，改用浅色图标底板、强数字和趋势说明。

### 6.7 表格、筛选区与分页

表格：

- 表头使用浅灰背景和中等字重。
- 行高统一为 52px 至 56px，缩略图行可提高至 64px。
- hover 只使用轻微表面色变化，不与条纹背景冲突。
- 操作列固定右侧，主操作前置，危险操作后置。
- 状态标签宽度尽量稳定，避免文本跳动。
- 空表格显示原因和下一步，不只显示“暂无数据”。

筛选区：

- 默认显示高频筛选，低频条件可收纳到“更多筛选”。
- 查询按钮改为“应用筛选”，重置按钮仅在存在条件时强调。
- 已生效条件以可关闭标签显示，并在动态胶囊中展示条件数量。
- 触发查询后保留筛选区高度，表格区域显示骨架或 loading。

分页：

- 总数与每页数量靠左，翻页操作靠右。
- 小于一页时弱化或隐藏页码控件，但保留总数信息。

### 6.8 Dialog、抽屉和确认框

- 简短表单使用 Dialog；字段多、需要上下文对照时使用右侧抽屉。
- 标题明确动作，例如“编辑课程”“停用会员”。
- Footer 主按钮使用具体动作文案。
- 危险确认框在正文中说明对象和后果，不使用通用“提示”标题。
- 打开后聚焦第一个可编辑字段；关闭后焦点回到触发按钮。
- 遮罩点击是否关闭按数据风险决定，编辑表单有未保存内容时不直接关闭。

### 6.9 Toast、提示条与状态反馈

- 成功 Toast 默认 2 秒，不阻塞操作。
- 失败 Toast 展示具体原因；需要用户处理时升级为页面内提示条。
- 同一错误不同时出现 Toast 和重复错误文案。
- 保存类操作使用“保存中 → 已保存”的连续状态。
- 401 跳登录保持现有逻辑，视觉上使用一次明确提示，避免并发重复。

### 6.10 Loading、骨架、空状态和错误状态

- 首次页面加载使用骨架；局部刷新使用组件内 loading。
- 骨架尺寸必须与真实内容一致，避免加载完成后布局跳动。
- 空状态由图形、原因和下一步组成。
- 列表筛选无结果时提供“清除筛选”。
- 网络错误提供“重新加载”，已加载的其他模块保持可用。
- 图表无数据使用轻量占位，不绘制空坐标系。

### 6.11 图片上传

- 上传区明确展示支持 JPG / PNG / WebP、最大 2MB，并按业务场景补充推荐比例。
- 选择文件后先在前端校验格式与大小；服务端继续作为最终安全边界。
- 上传中显示局部进度状态，禁用重复选择。
- 上传完成后在原位置交叉淡入预览图。
- “更换图片”和“移除图片”分开表达。
- 图片错误时显示占位图和重新选择入口。

### 6.12 图表

- 图表颜色、字体、网格线、Tooltip 使用全局主题。
- 网格线使用低对比分隔色，坐标轴不使用纯黑。
- Tooltip 使用半透明深色表面和 12px 圆角。
- 折线强调趋势，柱状图强调比较；不增加无业务意义的渐变面积。
- 热门课程名称较长时优先改为横向条形图，避免倾斜标签。
- 数据进入可使用 300ms 动画；筛选频繁变化时缩短至 180ms。

## 十、无障碍与可用性

- 正文和背景对比度至少达到 WCAG AA。
- 键盘焦点清晰可见，不使用 outline: none 后无替代方案。
- 所有触控目标不小于 44px × 44px。
- 禁用态除颜色外还需使用透明度、图标或说明文案。
- 表单错误通过 aria 或 Element Plus 现有语义关联到字段。
- 图表关键信息在 Tooltip 外仍可通过标题、单位和汇总数字理解。
- 支持减少动态效果设置。
- 操作名称保持一致：“保存排班”完成后提示“排班已保存”，“确认预约”完成后提示“预约成功”。

## 十四、最终设计决策

1. 采用“轻盈系统 × 训练节奏”，不采用全暗色训练舱或柔和会所风格。
2. 苹果风格以层级、材质、排版和反馈原则实现，不复制 Apple 品牌资产。
3. 珊瑚橙是健身品牌强调色，Apple 蓝继续承担操作语义。
4. 毛玻璃只用于导航和浮层，主体内容保持高可读实色表面。
5. “训练动态胶囊”是唯一重点强化的标志性交互。
6. 保留 Element Plus、uni-app、现有封装和全部业务逻辑。
7. 不增加动画库或新的 UI 框架。


## 十五、实施后补充（微信开发者工具实测，2026-08-16）

1. WXSS 选择器兼容性：
   - 小程序端不支持通配选择器 `*`；`prefers-reduced-motion` 的全局减少动态效果规则仅编译到 H5。
   - 清理了 `.list > * + *`，改用 flex + gap。
   - `:not([disabled])`、`[disabled]`、`nth-child` 等选择器已改为 class 绑定 + 显式类名，避免开发者工具 WXSS 编译风险。
2. 会员端登录：
   - `uni.request` 统一增加 10s timeout，避免异常挂起时按钮 loading 无法恢复。
   - 修复 `user.isLogin` getter 缺少响应式依赖导致“登录成功返回详情页后 pendingSlot 不消费”的问题。
   - 微信开发者工具「游客模式（touristappid）」会触发工具内部 `webapi_getwxaasyncsecinfo:fail`，并可能干扰登录等网络请求；本地调试请使用**测试号**或真实 AppID，并确认「不校验合法域名」保持开启。
3. TabBar 图标：
   - 已补充 6 张同风格线性本地图标（`miniapp/src/static/tabbar/`），选中态使用 #007AFF，普通态使用 #98989D。
