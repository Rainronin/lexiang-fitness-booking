# UI 验收问题修复实施计划

> **执行要求：** 当前会话按系统化调试与测试驱动方式逐项执行；每项先保留失败证据，再做最小修复并复验。

**目标：** 修复 UI 验收后确认的上传契约、未保存保护、键盘与读屏、移动端导航和后台首屏体积问题，同时保持业务流程与既有视觉方案不变。

**实现思路：** 服务端继续作为上传大小的安全边界，前端只对齐提示和预检；交互优先使用原生语义与 Vue Router 原生离开守卫；性能优化只把 Element Plus 从全量注册改为项目实际使用组件注册，不引入新依赖。

**技术栈：** Vue 3、Vue Router、Element Plus、Vite、uni-app、Express、Node.js。

**设计依据：** `docs/乐享健身UI重构设计方案.md`

## 全局约束

- 不改变预约、排班、认证等业务规则和接口结构。
- 不新增运行时或开发依赖。
- 保留既有苹果风格、设计令牌、动效节奏和响应式布局。
- 所有对话、文档、代码注释与错误提示使用中文。
- 只修改与已确认问题直接相关的文件。
