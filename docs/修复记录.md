## 修复过程中确认的附加事实

1. **better-sqlite3 v13 API 语义**：`db.transaction(fn).immediate` 是属性（值为 IMMEDIATE 事务函数），`.immediate()` 是立即执行事务并返回 null（首次验证时踩坑修正）。
2. **R-I4 触发前提被外键挡住**：`booking.schedule_id` 有 FK 引用且 `foreign_keys = ON`，有预约记录的排班在正常状态下无法删除；R-I4 空值守卫属防御性加固（验证时需临时关闭本连接 FK 模拟），同时说明此前审查低估了外键约束的保护作用。
3. **MP-C1 附带修复**：原条件编译下，非 H5/微信平台（如支付宝小程序）BASE_URL/UPLOAD_BASE 为 undefined，合并后全部平台均可导出。
