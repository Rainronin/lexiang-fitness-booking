# 演示图片

12 张课程封面和 5 张教练示意头像，均为本项目原创 SVG 几何插画；头像不代表真人照片。

- `course-1` 至 `course-3`：哈他、流、空中瑜伽。
- `course-4` 至 `course-6`：杠铃、壶铃、器械。
- `course-7` 至 `course-9`：单车、搏击操、尊巴。
- `course-10` 至 `course-12`：泰拳、柔术、拳击。

SVG 用于编辑，随附的 PNG 用于后台和小程序实际展示，运行时不需要转换器或新依赖。SVG 修改后，使用常规 SVG 渲染工具重新导出同名 PNG 即可。本次使用 Sharp 渲染，课程图为 800×480，头像为 320×320。

已有数据库无需重建。在 `server` 执行 `npm run art:refresh`，仅补齐缺失图片或替换 SHA-256 匹配旧种子占位图的文件；其他上传图片保持原样。浏览器如缓存旧图，刷新页面即可。

`npm run seed` 继续从本目录复制 PNG；该命令仍会重建数据库，不要为更新图片执行它。
